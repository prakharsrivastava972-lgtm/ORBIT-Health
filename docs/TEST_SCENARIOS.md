# Demo scenarios and test checklist

All data is SIMULATED. Load a scenario in Settings > Demo scenarios.

| Scenario | What to look for |
|----------|------------------|
| Nominal | No flags anywhere. Overall Normal. |
| Sleep and stress drift | Sleep and behavioral Attention flags, no Urgent. Check-in page shows sustained stress and fatigue. |
| Dehydration and elevated heart rate | Related Attention flags (fluid intake, heart rate, blood pressure, weight). Recommendations suggest hydration review. |
| Urgent escalation | Urgent status, escalation steps, support request that cannot be resolved by button. Send the summary through Comms. |
| Sparse data | No baselines, low confidence, missing-data notes, no-data metrics. |

Other checks: edit a profile, set a mission threshold and see the flag labeled mission-configured,
export, reset, import, and confirm the data returns.
