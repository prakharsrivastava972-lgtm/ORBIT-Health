# History, Reports and Comms

All demo data is SIMULATED. Nothing here is medical advice.

## History and Charts
- Charts and tables use only stored readings. Ranges: 7, 14, 30 days, All.
- Personal baseline band = median +/- usual variation (same method as the engine). Optional attention limits.
- General reference limits are illustrative, not astronaut-specific thresholds, not NASA values.

## Reports
- Status, unresolved and resolved flags, all metrics, behavioral summary, data-quality notes, limits.
- Print (white-on-black print stylesheet), copy text, download .txt.

## Flight Surgeon Comms (simulation)
- Crew message reaches the ground after a one-way delay. A scripted reply is stored at send time but shown only after
  one-way delay + response time + return delay. Real delays are shown for context; the demo uses shortened ones.
- The responder is rule-based. No real clinician. Emergency and self-harm wording gets a reply pointing to
  emergency procedures and behavioral health support.
